# PH7 vs PHP — Различия языков (автоматический перевод английской версии сделанный Чатом ГПТ)

| Где PH7 отстает от PHP7 и PHP8                                                                                                                                                         | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Короткий синтаксис массивов `$x = [1,2,3];` не поддерживается. [в планах] | Полная поддержка |
| Деструктуризация (короткий синтаксис list): `[$a,$b,$c] = $x;` не поддерживается. [в планах] | Полная поддержка |
| `__call()` и `__callStatic()` не возвращают значение [в планах] | Полная поддержка |
| Операторы `??`, `??=` и nullsafe `?->` отсутствуют | Полная поддержка |


| Где PH7 превосходит PHP (ближе к Си++)                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 64-битная целочисленная арифметика на всех платформах | 32 бита на 32-битных платформах, 64 бита на 64-битных |
| Нативная поддержка UTF-8 для строк, идентификаторов, констант, переменных и имён функций (классов и т.д.) | Не осилили |
| К статическим свойствам можно обращаться и изменять их через объект с помощью оператора `->` | В PHP так обращаться к статическим переменным нельзя — синтаксическая ошибка |

```php
class MyClass {
  public static $a = 5*5;  //
}

$n = new MyClass;
$n->a <<= 1;

echo MyClass::$a; /* Выведет 50 */
```

| PH7                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Конструкторы и деструкторы могут быть перегружены точно так же, как и любые другие методы класса. Если конструктор отсутствует, атрибуты сохраняют свои значения инициализации (в том числе любые сложные выражения) и не обнуляются. | Перегрузка не поддерживается, поддержки сложных выражений нет |
| Значения аргументов по умолчанию могут быть сложными выражениями. То же самое касается `const`, `static` и случаев `enum` | PHP не поддерживает сложные выражения в качестве параметров по умолчанию |

```php

const Hello = 'Hello' . rand_str(15); // Инициализируется один раз

function test($callback = function(){ echo "Hello World!\n";})
{
   /* Проверяем, что перед нами callback */
  if( !is_callable($callback) ){
     die("Expecting a callback");
  }
  /* Вызываем callback */
  $callback();
}

/* Вызов без аргументов */
test(); /* Вы увидите: Hello World */

/* Вызов с одним аргументом */
test(function(){ echo "Welcome guest\n";}); /* Вы увидите: Welcome guest */

test(10); /* Вы увидите: Expecting a callback */

```

| PH7                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Перегрузка функций (по количеству и типам аргументов) | PHP не поддерживает перегрузку функций |

```php
function foo(int $a) {
  echo "a is integer\n";
  var_dump($a);
}

function foo(array $a) {
  echo "a is an array\n";
  var_dump($a);
}

foo(52); /* a is integer*/
foo(array(14,__TIME__,__DATE__)); /* a is an array  */

```
| PH7                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Оператор запятой в выражениях и в case-ах enum | PHP не поддерживает оператор запятой |

```php
$a = 25,$b = $a << 1 ,test();

/* Выводим значения $a и $b */
function test(){
  global $a,$b;
  echo "\$a = $a \$b= $b\n"; /* Вы увидите: $a = 25 $b = 50*/
}

enum Hello: int {
  case A=1, B=2, C=3;  // Можно через запятую, но обязательно инициализированные значения
  case H = 66;
}
```

| Где PH7 отличается от PHP                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `function foo(string $x): int { ... }` — тип параметра **автоматически преобразует** аргумент в `string`; тип возврата автоматически преобразует возвращаемое значение | `function foo(int $x): int { ... }` — типы параметров и возврата используются для проверки совместимости типов согласно системе типов PHP |
| `function foo(int $x) { ... }` — `foo("66.6")` получает `66`. | `function foo(int $x) { ... }` — **проверяется совместимость типов** по правилам PHP, преобразование не выполняется |
| `function foo(): int { return "666"; }` — возвращает `int(666)`. | `function foo(): int { return "666"; }` — ошибка |
| `function(int $x):mixed { ... }` — анонимная функция (замыкание). Типы параметра и возврата используют автоматическое преобразование | `function(int $x):mixed { ... }` — анонимная функция (замыкание). Типы параметра и возврата используются только для проверки типов |
| `fn($x) use ($factor) :int => $x * $factor` — стрелочная функция **требует явного захвата переменных**; возвращаемое значение преобразуется в `int`. | `fn($x): int => $x * $factor` — переменные автоматически захватываются из внешней области видимости; тип возврата должен соответствовать типу возврата замыкания |

```php
function test(string $x) {
  var_dump($x);            
}

function test2(int $x) {
  var_dump($x);
}

function test3($x) {
  var_dump($x);
}

test(10);       // <-- Выведет "string(2, '10')"
test2("10.56"); // <-- Выведет "int(10)"
test3("10.56"); // <-- Выведет "string(5,'10.56')", т.е. без преобразования

function test4() :int {
  return '42';
}

var_dump(test4()); // <-- Выведет "int(42)", т.е. возвращаемое значение было автоматически приведено к типу возврата функции (int)

```

| PH7                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Обычный enum:** `enum Color { case RED; case GREEN; }` — case-ы являются **константами и генерируются автоматически**. | **Обычный enum:** `enum Color { case RED; case GREEN; }` — **case-ы не имеют связанных скалярных значений.** |
| **Backed enum (с значениями):** `enum Color : int { ... }` — case-ы могут иметь значения любого типа (не обязательно соответствующие объявленному типу enum), включая сложные выражения и вызовы функций; у enum есть объявленный тип, **используемый для автоматического преобразования при потреблении значения** как этого типа enum. | **Backed enum:** `enum Color : int { ... }` — каждый case обязан соответствовать объявленному типу `int` |
| **String backed enum:** `enum Color : string { ... }` — значения enum преобразуются в `string` при использовании как этого типа. | **String backed enum:** `enum Color : string { ... }` — каждый case обязан соответствовать объявленному типу `string` |
| **Mixed enum:** значения case-ов могут иметь разные типы. При объявлении case-ов проверка типов не выполняется. | **Mixed enum:** эквивалента backed-enum с смешанными типами не существует; у backed enum всегда один объявленный тип-носитель. |
| `enum E : int { case A = "66.6"; }` — сам case сохраняет значение `"66.6"`; преобразование происходит при использовании там, где ожидается `E` (например, при вызове `function func(E $x)`, `$x` будет автоматически приведён к `int` (тип enum — `int`)) | `enum E : int { case A = "66.6"; }` — недопустимое объявление case у backed-enum |
| `function foo(E $x) { ... }` — `E` трактуется как объявленный тип enum; аргумент автоматически преобразуется к этому типу. | `function foo(E $x) { ... }` — аргумент должен удовлетворять типу enum; PHP не трактует тип enum как его скалярный тип-носитель |
| **Автонумерация:** `case A; case B; case C;` — неявные значения генерируются автоматически. | Общего эквивалента автонумерации case-ов нет. |
| **Автонумерация с явными значениями:** `case A; case B = 10; case C;` — неявные значения продолжаются независимо; `A` и `C` получают автоматически сгенерированные значения. | Эквивалентного механизма нет. |
| Значения case-ов enum могут использовать существующий в PH7 механизм выражений для констант класса. | Значения case-ов enum подчиняются ограничениям PHP на константные выражения в enum. |

```php
// Enum без автопреобразования (mixed):
//
enum Loo :mixed {
  case Name1 = 10;
  case Name2 = 10.2;
  case Name3 = 'Hello'.rand_str(4);
}

// При использовании как `Suit $x` в аргументах функции будет автоматически преобразовано в строку
//
enum Suit :string {
  case Name1 = 10;
  case Name2 = 10.2;
  case Name3 = 'Hello'.rand_str(4);
}

function test(Suit $x) {   // Эквивалентно test(string $x)
  var_dump($x);            // <-- Выведет "string(...)"
}

function test(Loo $x) {       // Эквивалентно test(mixed $x)
  var_dump($x);               // <-- Выведет реальный тип $x
}
```

| PH7                                                                                                                                                                  | PHP                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Closure — это `string`; например `$a = function() {}; var_dump();` выведет "string(9,'closure_1')" или что-то похожее | Closure — это объект со свойствами и методами |
| `:never` модификатор автоматически вставит опкод HALT если произойдет возврат из функции | PHP проверяет на этапе компиляции, что не всегда возможно сделать статическим анализом |
