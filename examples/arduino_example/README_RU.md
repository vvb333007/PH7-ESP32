## Пример для Arduino

Пример состоит из трёх файлов:

```
arduino_example.ino
example_scripts.tar
partitions.csv
```

### Требуемые библиотеки

Перед компиляцией необходимо установить следующие библиотеки:

* **TARFS** версии **0.1.5** или выше
* **PH7-ESP32** версии **0.0.1** или выше

Последние версии библиотек доступны по ссылкам:

* TARFS: https://github.com/vvb333007/tarfs
* PH7-ESP32: https://github.com/vvb333007/PH7-ESP32

### Загрузка файловой системы

Перед загрузкой скетча необходимо записать архив `example_scripts.tar` во Flash-память ESP32.

Пример команды:

```bash
esptool.exe --chip esp32s3 --port COM4 --baud 921600 write_flash 0x310000 example_scripts.tar
```

Параметры команды:

* `esp32s3` — модель используемого чипа ESP32. При необходимости замените на свою модель.
* `COM4` — номер последовательного порта вашей платы. Замените на актуальный порт.

Адрес загрузки:

```
0x310000
```

### Запуск примера

После записи `example_scripts.tar`:

1. Откройте файл `arduino_example.ino`.
2. Скомпилируйте проект.
3. Загрузите скетч в ESP32.
