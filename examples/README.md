`api_examples/` --> Assorted examples on how to use PH7 from your C code
`arduino_example/` --> An example for Arduino IDE
`linux_windows_example/` --> A standalone PHP interpreter for Linux or Windows (Cygwin)
`amalgamated/` --> A standalone PHP interpreter for Linux or Windows (Cygwin), as a single source file (enables more agressve compiler optimizations)

`test_files/` --> A bunch of small .php programs, demo of the language extensions. To be used with PH8 interpreter, which in turn is built as `amalgamated` or as `linux_windows_example` executable
