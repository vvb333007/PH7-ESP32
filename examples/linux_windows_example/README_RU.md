## Примеры для Linux / Windows (Cygwin)

Пример состоит из двух файлов:

```text
ph7_interp.c
Makefile
```

### Сборка

Для создания автономного PHP-компилятора/интерпретатора выполните:

```bash
make
```

После успешной сборки будет создан исполняемый файл, который можно использовать для запуска PHP-скриптов без внешнего интерпретатора PHP.
