PH7 Porting Plan

++++1. De-amalgamate the codebase and make it fully compilable in a Cygwin environment.

2. Memory backend: use PSRAM whenever it is available.

3. Refactor pthread-style mutexes to use FreeRTOS mutexes. Get rid of pthreads, FreeRTOS has native API for this

4. Implement POSIX functions such as 'getuid()', 'getpid()', etc.** where practical. At minimum, implement 'getpid()'.

5. Review and refactor 'vfs.c' and 'UnixVfs' to use TarFS as the primary filesystem backend.
   PH7 relies on a number of POSIX filesystem functions that are implemented as no-ops or only 
   partially supported in ESP-IDF. 

   These functions should be carefully reviewed to determine which ones are actually required by 
   PH7 and how they should be implemented on FreeRTOS.

6. Remove all WIN32-specific code completely.
